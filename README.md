# Carboneto 🏀

Carboneto é um aplicativo multiplataforma voltado à organização e criação de treinamentos para o basquetebol. Idealizado para atender treinadores e atletas de diversos níveis, o projeto promove uma abordagem técnica e estratégica ao processo de treinamento esportivo, democratizando o conhecimento e auxiliando na evolução técnica, física e tática.

## 🚀 Funcionalidades

O aplicativo foi desenhado para otimizar o tempo de planejamento dos treinadores e dar autonomia aos atletas. As principais funcionalidades incluem:

 - Cadastro de Usuários: Autenticação segura com perfis distintos (atletas e treinadores).

 - Biblioteca de Treinos: Acesso rápido a exercícios organizados de forma modular por categorias (técnicas, físicas e táticas).

 - Treinos Personalizados: Ferramenta para elaboração de planos de treinamento adaptados às necessidades específicas de cada atleta.

 - Histórico de Atividades (Em desenvolvimento): Acompanhamento do progresso dos usuários para ajustes estratégicos de acordo com os resultados.

 - Recomendações Inteligentes (Em desenvolvimento): Estrutura lógica para recomendação automática de exercícios baseada nos dados do usuário.

## 🛠️ Tecnologias Utilizadas

O Carboneto adota uma arquitetura cliente-servidor moderna, garantindo escalabilidade e compatibilidade entre plataformas.

 Frontend / Mobile: Flutter - Framework utilizado para criar uma interface responsiva, fluida e compatível nativamente com dispositivos Android e iOS.

Backend / Cloud Services: Firebase responsável por:
 - Autenticação de usuários.
 - Banco de Dados em tempo real (Realtime Database).
 - Armazenamento de arquivos (Cloud Storage).
 - Design & Prototipação: Figma.
